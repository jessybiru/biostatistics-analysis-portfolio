# Biostatistics Analysis Portfolio

**Jesca Birungi**

A collection of R Markdown and Stata scripts documenting my analytical work and providing practical examples for students learning applied
biostatistics.

Datasets are not included. Each activity has its own folder with code, data requirements and instructions.

## Activities

| Activity | Software | Location |
| --- | --- | --- |
| Structural equation modelling | Stata | [SEM tutorial](sem-stata/) |

An ESS data-cleaning and harmonization example in R Markdown is being prepared for addition.

## Using the code

Open an activity folder and read its README before running the code. Obtain the required data separately and adapt paths and variable names
to your own project.

## Attribution and validation

Adapted examples identify their original sources. Each activity describes the work contributed and its validation status.

The current SEM script has been reviewed but still requires execution in Stata before it can be described as tested.
